THESILHOUETTEGIRL

Complete static website with 11 pages and a 404 page.
To run: extract this folder, open a terminal here, and run:
python -m http.server 8000
Then visit http://localhost:8000

Upload the contents of this folder to any static web host.
Artwork and original descriptions are taken from the supplied portfolio.
Favorites and reflection notes stay in local browser storage.
The contact page copies a message; it does not send it.
Fonts load from Google Fonts; system fallbacks are included.
